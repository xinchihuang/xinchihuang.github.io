# Human-Centered Robotics REU website

This version is intentionally self-contained:

- `index.html` includes all CSS and JavaScript.
- `assets/images/` contains only the replaceable carousel images.
- Upload the entire folder contents to the root of your GitHub repository.

## GitHub Pages

1. Create a repository, for example `hcr-reu`.
2. Upload `index.html` and the `assets` folder.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)`.
5. Visit `https://xinchihuang.github.io/hcr-reu/`.

## Replace carousel images

The current files are:

- `assets/images/slide-1.svg`
- `assets/images/slide-2.svg`
- `assets/images/slide-3.svg`

You may replace them with files using the same names, or edit the image paths in `index.html`.
